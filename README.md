# CampusPulse - (Mini Project)

An AI-driven campus placement automation system.

## Branches

- **`mini-project`** - Stable, submission-ready code
- **`develop`** - Daily development branch

## Tech Stack

- **Frontend:** Angular 17+
- **Backend:** Node.js + Express
- **Database:** MongoDB Atlas
- **AI:** Python + Sentence-BERT

## Setup Instructions

1. Clone the repository
2. Run `npm install` in both `backend/` and `frontend/` folders
3. Create a `.env` file in `backend/` with your MongoDB URI
4. Run `npm run dev` in `backend/` and `ng serve` in `frontend/`
